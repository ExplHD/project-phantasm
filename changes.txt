Script API belum bisa baca rarity item, jadi core/itemRarity.ts di-generate otomatis tiap rgl run sama filter lokal baru item_rarity (filters/item_rarity/main.mjs, jalan sebelum esbuild di profile default dan package-file). Filter ini baca minecraft:rarity dan minecraft:hover_text_color dari semua JSON di BP/items, jadi item baru langsung ikut tanpa nambah id manual. Daftar rarity item vanilla ada di filter itu, diambil dari kolom Bedrock di minecraft.wiki/w/Rarity dan semua id-nya dicek ke @minecraft/vanilla-data - zeromaster178
