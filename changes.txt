1.5.1 (The Bugfix Update):

# Removal
- Removed the debug log spam that printed on every ore mined - ExplerHD

# Changes
= Rewrote the Dynamic Light System: no more flickering when switching items, lights are placed instantly, and they only spawn on air or liquid blocks so they won't break tall grass, flowers, or doors - ExplerHD
= Health Bar now uses the native on-screen display, so it no longer spams the chat and shows correctly on respawn - ExplerHD
= Fixed a crash ("setTitle of undefined") that occurred whenever a mob took damage - ExplerHD
= Overhauled the Guidescreen: fixed wrong weapon titles and a wrong drop source, cleaned up typos, and corrected outdated HP data - ExplerHD
= Fixed the Damage Indicator icons being mispositioned - ExplerHD
= Moved the Dash cooldown scoreboard to be initialized when a player joins - ExplerHD

# Addition
+ Added a Getting Started page to the Guidescreen with a recommended progression path, plus a welcome message on first join - ExplerHD
+ Added a crafting recipe to turn a Rusted Fortune Coin into 4 Gold Blocks - ExplerHD

1.5.0 (The Great Stability):

# Removal
- Removed the Glyph System, but you can still use the glyphs available in Phantasm - ExplerHD
- Removed the mining functionality from Legendary Weapons, as they were never designed for that purpose - ExplerHD
- Removed the Direct Hit feature from Legendary Weapons and Seiketsu - ExplerHD

# Changes
= Refactored the Custom Mace system - ExplerHD
  => Known Issue: Density damage from this weapon is still extremely high, and Breach Armor Penetration has not been implemented yet.
= Reworked the Damage Indicator system to use Runtime Particles - ExplerHD
= Changed Structures from fixed ground positions to locatable underwater structures - ExplerHD
= Updated the Soul of Nature boss fight to follow the new structure generation (underwater boss fight) - ExplerHD
= Adjusted the placement of the Crimson Overgrowth structure to make it more logical and visible - ExplerHD
= Increased Seiketsu damage by +4 - ExplerHD
= Slightly updated the visuals of The Bleeding Spire attack - ExplerHD
= Rebalanced the damage of all Legendary Weapons so they can compete with enchanted Epic Weapons - ExplerHD
= Made Soul of Nature, Punicea, and Auric Automaton have 650 HP, 3000 HP, and 1750 HP due to Recent Weapons changes. - ExplerHD
= Added support for Fire Aspect, Knockback, and Weakness on Legendary Weapons - ExplerHD
= Updated all Legendary Weapons so their attack patterns now loop continuously without an ending cooldown - ExplerHD
= Fixed a bug where upgrading Dash to Level 2 would display "Insufficient Experience Level" instead of "Maximum level of Dash is reached." - ExplerHD

# Addition
+ Added the `damage_number` and `damage_icons` particles - ExplerHD
+ Added the Better than Mending feature - ExplerHD
+ Added a Combat Dummy - ExplerHD
+ Added a Turtle Shell item to the Prismarine Boss Arena to make the boss fight in that arena easier - ExplerHD
+ Added Rusted Fortune Coin, which doubles ore drops, and the Item Magnet Ore. Both can be obtained from a 1% chance when mining any ore - Passive Type - ExplerHD
+ Added Condensed Sea Nature, providing much longer underwater breathing and slightly faster health regeneration while underwater - Passive Type - ExplerHD
+ Added Guidescreen that will appears at first join or an Add-On Update is applied - ExplerHD & ZeroMaster178
