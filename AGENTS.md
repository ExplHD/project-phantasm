# AGENTS.md — Project Phantasm

Minecraft Bedrock addon (Regolith project). Behavior pack `packs/BP`, resource pack `packs/RP`, content namespace `ph:`.

## Commands

- Install: `bun install` (or `npm install`) + `rgl install` (Regolith filters).
- Dev build + export to Minecraft dev folder: `rgl run`; live rebuild: `rgl watch`.
- Before commit/release: `rgl apply default` so confirmed work lands in `packs/`.
- Release artifact (obfuscated `.mcaddon`): `package-file` profile in `config.json` (`esbuild` → `js_obfuscator` → `mcaddon`).
- No `package.json` scripts, no tests, no lint, no CI. Typecheck ad hoc: `npx tsc --noEmit -p data/scripts`.

## Code layout

- Script source is `data/scripts/`, organised in layers. A module may only import from layers above its own, never sideways or downward.
  - `main.ts` — entry point (must stay at this path; the esbuild filter and BP manifest both resolve it). Wiring only, no logic.
  - `core/` — helpers and constants. Imports nothing from the project.
  - `systems/` — gameplay systems reacting to world state.
  - `features/` — content features (`weapons/`, `blocks/`, `mace/`).
  - `ui/` — forms and guide screens (`forms/`, `guide/`).
  - `events/` — event subscriptions (`index.ts`, `loader.ts`).
- `packs/BP/scripts/main.js` is generated by the `esbuild` Regolith filter — never edit it by hand.
- `data/scripts/tsconfig.json` is `strict`, `noEmit`, `moduleResolution: bundler` with `~/*` → `./*` path alias.
- `@minecraft/server ^2.8.0` + `@minecraft/server-ui ^2.1.0`; BP manifest pins `min_engine_version` and `@minecraft/server 2.6.0` — keep header/dependency versions in sync when bumping.

## Conventions

- All custom ids use `ph:` prefix. Item lore/tiers live in `data/scripts/phantasmConstants.ts` (`addLore`, `LEGENDARY_TIER`); scoreboard objectives are registered in `data/scripts/loader.ts` — add new ones there.
- Log changes in `changes.txt` with `< - / = / + > <Removal/Changes/Addition> - <Name>` under `# Removal` / `# Changes` / `# Addition` per version.
- `.vscode/settings.json` pins Rockide pack paths (`./packs/BP`, `./packs/RP`) and empty `json.schemas` — leave both alone or JSON/Molang autocomplete breaks.

## Verify

- No automated verification; test in-game via `rgl run`/`rgl watch` and the Content Log.
